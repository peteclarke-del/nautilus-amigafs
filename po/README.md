# AmigaFS translations

Run `make messages` after changing desktop-facing text. Translate
`po/amigafs.pot` with a gettext editor, compile the catalogue to
`src/amigafs/locale/LOCALE/LC_MESSAGES/amigafs.mo`, and test it with the
appropriate `LANGUAGE` value. See `docs/localisation.md` for the
workflow and placeholder rules.
